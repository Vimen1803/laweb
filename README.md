Formato del env:

MONGODB_URI= la db principal <br>
WEREWOLF_MONGODB_URI= la db donde esta el ww (puede coincidir con la principal) <br>
DISCORD_CLIENT_ID=id del bot <br>
DISCORD_CLIENT_SECRET=secret del bot <br>
NEXTAUTH_SECRET= muchas teclas random al azar y si ya existe no lo cambies <br>
NEXTAUTH_URL=url del hosting donde se despliegue <br>
BRAWL_API_TOKEN= la api de supercell <br>
DISCORD_BOT_TOKEN= token del bot <br>
DISCORD_GUILD_ID= id del servidor <br><br>
AUTH_SECRET= lo mismo que el NEXTAUTH_SECRET <br>
AUTH_URL= url del hosting donde se despliegue <br>
