Formato del env:

MONGODB_URI= la db principal
WEREWOLF_MONGODB_URI= la db donde esta el ww (puede coincidir con la principal)
DISCORD_CLIENT_ID=id del bot
DISCORD_CLIENT_SECRET=secret del bot
NEXTAUTH_SECRET= muchas teclas random al azar y si ya existe no lo cambies
NEXTAUTH_URL=url del hosting donde se desplegue
BRAWL_API_TOKEN= la api de supercell
DISCORD_BOT_TOKEN= token del bot
DISCORD_GUILD_ID= id del servidor

AUTH_SECRET= lo mismo que el NEXTAUTH_SECRET
AUTH_URL= url del hosting donde se desplegue
